# 🛒 E-Commerce Funnel Analysis

## 📌 Project Overview

This project analyzes user behavior data from a large multi-category online store to understand how customers move through the purchasing funnel: **View → Cart → Purchase**.

**Business Problem:** The company sees high traffic but doesn't know where users drop off or which channels/categories drive conversions.

**Goal:** Identify drop-off points, calculate conversion rates, and provide actionable recommendations to increase revenue.

---

## 📊 Dataset

- **Source:** [E-Commerce Behavior Data from Multi-Category Store](https://www.kaggle.com/datasets/mkechinov/ecommerce-behavior-data-from-multi-category-store) (Kaggle)
- **Time Period:** October 2019
- **Size:** 42.4 million events
- **Event Types:** `view`, `cart`, `remove_from_cart`, `purchase`
